# HDI_4DVP_AutoRowHeight

A 4D v17 **HDI** (How Do I) binary database converted to a 4D project using 4D 21. The codebase was then updated and cleaned up with the help of **GitHub Copilot**.

## Origin

This project started as a binary `.4DB` example database originally distributed with 4D {version}. It was converted to the modern project architecture (`.4DProject`) using 4D 21's built-in binary-to-project conversion tool.

- **Blog post:** https://blog.4d.com/automatic-row-height-in-listboxes-a-new-4d-view-pro-feature/

- **Original download:** https://downloads.4d.com/Demos/4D_v16_R5/HDI_4DVP_AutoRowHeight.zip
